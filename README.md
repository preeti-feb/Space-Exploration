# "Space Exploration"

Welcome to Space Exploration, This is a static project that created to explore and share information about astronomy. In this project, 
you will explore a space gallery featuring planets, satellites, and galaxies. You can also read about latest missions that 
researchers and scientist are working on, such as 'Artemis II', 'Voyager 1' and more. This project is designed made for those 
who want to read about understand latest missions from NASA's.


## Features 

* **Space Gallery:** Browse through stunning visuals of planets, satellites, and galaxies.
* **Latest Missions:** Read up-to-date information on major space exploration efforts like Artemis II and Voyager 1.
* **Responsive Design:** Clean and assessible layout optimized for Tablet and Mobile screens including (768px and 480px) sizes.


## Technologies Used

* **HTML5:** Structuring the content of the web pages.
* **CSS3:** Styling and making the project visually appealing, making it responsive for Tablet and Mobile.
* **Git & GitHub:** Version control and deployment.
